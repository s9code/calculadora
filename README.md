# Calculadora

Proyecto del currículo Full Stack JavaScript de [The Odin Project](https://www.theodinproject.com/).

## 🎯 Objetivo

Construir una calculadora interactiva en el navegador aplicando:

- Manipulación del DOM para actualizar dinámicamente la interfaz.
- Gestión de eventos mediante botones y eventos del usuario.
- Uso de funciones para realizar operaciones matemáticas.
- Control del estado de la calculadora y de los valores introducidos.
- Uso de condicionales para determinar las operaciones a realizar.
- Integración de HTML, CSS y JavaScript para crear una aplicación interactiva

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
